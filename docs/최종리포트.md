# 10일간 내 영어는 실제로 늘었나? (수다백단 사용 기록 분석)

## 1. 배경

직접 만든 AI 회화앱 '수다백단'을 10근무일(11/5~11/18) 동안 쓰고, 내 메시지 280개(대화 31회)로 영어가 늘었는지 확인했다. 전반부(메시지 113개)와 후반부(167개)를 비교했다.

## 2. 핵심 결과

**늘어난 것: 정확성 (가능성 있음)**

- 교정받은 메시지 비율 68% → 53% (-15%p, 95% 구간 -25~-5%p), 메시지당 실수 0.69 → 0.51개.
- 문장 길이 구성을 맞춰도 54%라 짧아져서 생긴 착시가 아니다. 같은 스타일을 반복한 3쌍(하루 19~44개)도 모두 마지막 회가 낮았다.

**그대로인 것: 고질 실수, 문장 복잡성**

- 전반부에 2일 이상 반복된 실수 14개 중 8개(57%)가 후반부에도 나왔다. 전부 질문 어순·관사·be동사 같은 문법이다. 한 번만 나온 실수는 16%(9/55)만 다시 나왔다.
- 긴 문장(10단어 이상)은 49% → 33%로 오히려 줄었고, 어휘 다양성(MSTTR)은 0.77 → 0.78로 그대로다.

## 3. 원인 진단

- **고질 실수가 남는 이유**: 앱은 틀린 순간에 고쳐 줄 뿐 같은 규칙을 다시 써 볼 기회가 적다. 대화에 몰래 넣는 연습에서 맞게 쓴 건 30번 중 7번, 또 틀린 건 20번이었다 (맞게 쓴 횟수는 전반 1/15 → 후반 6/15).
- **문법만 남는 이유**: 표현 실수는 특정 단어에 묶여 다시 나올 일이 적다 (2일 이상 반복 5%, 2/41). 문법은 모든 문장에 쓰여 41%(20/49)가 반복됐다.
- **문장이 짧아진 이유**: 실력보다 상황 탓이 크다. 가장 짧았던 11/16(평균 6.7단어)은 짧은 대답이 많은 화상 회의 상황극과 빨래하며 한 음성 대화였다.

## 4. 서비스 개선안

1. **고질 실수 복습 카드**: 2번 이상 틀린 문법 규칙을 3~4일 간격으로 대화 전에 문장 고치기 1~2개로 낸다.
   - 근거: 반복 실수 재발률 57% (8/14), 문법 실수(48개)의 절반 가까이가 4근무일 안에 재발 (생존 분석).
2. **연습 대상 공개와 성공 표시**: 오늘 연습할 규칙을 미리 알려 주고, 맞게 쓰면 바로 표시한다.
   - 근거: 숨긴 연습의 성공은 7/30, 다시 틀림은 20/30.
3. **'틀림'과 '더 자연스러운 표현' 구분**: 맞는 문장은 실수에서 빼고 추천 표현으로 따로 보여 준다. 그래야 복습 카드에 진짜 실수만 들어간다.
   - 근거: 직접 검수한 30건에서 AI 실수 기록의 17%(3/18)가 맞는 표현이었다.

## 5. 한계

사용자 1명·10일·메시지 280개라 일반화할 수 없다. 정확성은 AI 판정(검수 일치율 87%, 30건, 판정자 1명)에 기대 하락 폭이 과대평가됐을 수 있다. 음성은 2회뿐이라 유창성은 보지 못했다.
