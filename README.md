# 수다백단 (Suda 100)

> *Suda level: 100. Subtitles: 0.*

AI와 하루 20~30분 **영어로 수다를 떨면서** 원어민처럼 말하는 법을 익히는 Windows용 데스크톱 앱입니다.
내가 쓴 문장이 맞는지, 원어민이라면 어떻게 말하는지 대화 흐름을 끊지 않고 옆에서 알려 주고,
자주 틀리는 표현은 기억해 두었다가 다음 대화에 은근히 다시 나오게 만듭니다.
시험 보는 느낌 없이 천천히, 길게 가는 트레이닝이에요.

> **suda(수다)**: 부담 없이 이것저것 이야기하는 것. 목표는 일상 영어 회화, 그리고 영화를 자막 없이 보는 것.

## 주요 기능

- **네 가지 대화 모드**
  - ☕ 일상 대화: 날마다 다른 주제, 가끔은 지난 이야기 이어 가기
  - 💼 비즈니스: 회의 일정, 협상, 보고 같은 업무 상황
  - 🔤 동사 집중: get, take, put처럼 뜻이 여러 개인 동사를 여러 의미로 쓰게 유도
  - 🧩 표현·문형: be going to, not only A but also B 같은 표현을 자연스럽게 쓰게 유도
- **흐름을 끊지 않는 교정**: 내 말풍선 아래에 "원어민은 이렇게도 말해요" 카드 (펼치고 접기), 짧게 답하면 가끔 "이렇게 이어 말할 수도 있어요"
- **한국어로 물어보기**: 대화 중에 "○○ 영어로 뭐야?"라고 물으면 옆에 한국어 도움말 카드로 답하고 대화는 계속
- **AI 답장의 한국어 번역**: 말풍선마다 접힌 번역 카드, 필요할 때만 펼쳐 보기
- **답만 하는 대화가 아니에요**: AI가 자기 이야기를 하거나, 살짝 반대하거나, 비밀을 숨기거나, 역할을 바꾸는 등 날마다 방식을 바꿔서 내가 질문하고 이끌게 만듦
- **기억**: 지난 대화 주제, 나에 대한 정보, 자주 틀리는 표현을 기억하고 다음 대화에 은근히 녹여 다시 연습
- **음성**: AI 답장을 원어민 목소리로 듣기 (천천히 / 보통 / 원어민 속도), 마이크 버튼을 누르고 말하기
- **일일 리포트**: 오늘 배운 표현, 🔁 또 나온 표현, ✨ 이제 맞게 쓴 표현
- **주간 평가서**: 코치가 쓴 편지와 함께 성실도·의지력·회화력·교정 이해력·대화 주도력 (10점 만점), 부족한 점과 다음 주 방안
- **수준이 조금씩 올라가요**: 주마다 대화 수준이 올라감. 처음엔 티 나게, 높아질수록 천천히
- **기록**: 지난 대화를 교정·번역 카드 그대로 다시 보기

## 필요 환경

- Windows 10 / 11
- [Python 3.10 이상](https://www.python.org/downloads/) — 설치할 때 **"Add python.exe to PATH"** 체크
- [Google Gemini API 키](https://aistudio.google.com/apikey) — 무료 등급으로 하루 30분 정도는 충분해요

## 설치와 실행

1. 이 저장소를 내려받습니다. (초록색 **Code** 버튼 → **Download ZIP** 후 압축 풀기, 또는 `git clone`)
2. 폴더 안의 **`install.bat`** 을 더블클릭해서 필요한 패키지를 설치합니다.
3. **`run.bat`** 을 더블클릭해서 실행합니다.
4. 왼쪽 메뉴 **[설정]** 에서 Gemini API 키를 넣고 저장합니다.
5. **[오늘 대화]** 에서 모드를 고르고 **▶ 대화 시작** 을 누르면 끝!

처음 마이크를 쓸 때는 음성 인식 모델(약 150MB)을 내려받느라 잠깐 "음성 준비 중…"으로 보여요.

## 데이터

실행하면 프로그램 폴더에 아래 파일이 만들어집니다. 이 파일들은 저장소에 올라가지 않습니다.

| 파일 | 내용 |
|---|---|
| `settings.json` | Gemini API 키, 목소리, 하루 목표 시간 |
| `data/` | 대화 기록, 기억, 일일 리포트, 주간 평가서 |

## 알아 두실 점

- 대화 내용은 답장을 만들기 위해 **Google Gemini**로 전송됩니다. 무료 등급에서는 Google이 서비스 개선에 사용할 수 있으니, 실제 회사 정보 같은 민감한 내용은 넣지 마세요.
- AI 답장을 읽어 줄 때 문장이 **Microsoft 온라인 음성 서비스**로 전송됩니다.
- 마이크 음성은 PC 안에서 글자로 바꾸며(faster-whisper) 밖으로 보내지 않습니다.
