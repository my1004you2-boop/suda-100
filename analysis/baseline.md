# 기준선 (Baseline)

10일간의 변화를 비교할 출발점. 계산: `python -m analysis.prep` → `python -m analysis.metrics` (2026-11-10 기준 데이터).

## 기준선을 두 개로 나눈 이유

11/4 데이터는 두 가지 점에서 이후 데이터와 조건이 다르다.

1. **기록 방식이 다르다.** 실수 이름표·종류 기록 방식을 11/5 오전에 고쳤다 (`prompt_version` 빈칸 → `2026-11-05`).
2. **채점한 AI 모델이 다를 가능성이 높다.** 기본 모델을 `gemini-2.5-flash` → `gemini-3.5-flash-lite`로 바꾼 커밋이 11/4 18:07인데, 11/4 주요 대화 2회는 그 전(15:58, 16:59)에 했다. 11/4 세션에는 모델 기록이 없어 확정할 수는 없다(추정).

그래서 지표를 **AI가 판정에 관여하는지**로 나눠 기준선을 정한다.

| 지표 종류 | 기준선 날짜 | 이유 |
|---|---|---|
| **내 문장에서 직접 세는 지표** (단어 수, 어휘 다양성, 한국어 섞임) | **11/4** | AI 판정과 무관. 앱을 쓰기 시작한 첫날이라 가장 순수한 출발점 |
| **AI가 판정하는 지표** (교정 비율, 실수 수, 주도·질문 비율) | **11/5** (1일차) | 판정 모델·기록 방식이 분석 기간과 같은 첫날 |
| **재발 지표** | 기준선 없음 | 이전 기록이 쌓여야 계산되는 누적 지표. 11/5 이후 추이로 본다 |

## 해석할 때 주의할 점

- **하루 표본이 작다** (메시지 19~29개). 메시지 1개가 비율을 3~5%p 움직인다.
- **대화 스타일이 하루 단위로 바뀐다.** 11/5 목표 달성 역할극, 11/6 AI가 자기 이야기, 11/9 AI가 살짝 반대. 주도율·질문 비율은 스타일 영향이 크다(11/5 18.5% → 11/6 58.6%). 중간 점검(5일차)부터 스타일별로 나눠 본다.
- **음성 입력은 아직 0건**이라 입력 방식 비교(C1)는 기준선이 없다.
- 11/4 마지막 대화는 108초로 짧다(메시지 1개). 기준선에 포함했지만 영향은 작다.
